# ♨ 九州 温泉手帖

九州7県の温泉を記録するスマホ向けのWebアプリです。行った温泉・行きたい温泉の記録、星評価・感想、写真のアルバム、県ごとの制覇状況を残せます。

## 公開ページ

https://iwbea2012-prog.github.io/onsen-techo/

## 仕組み

- HTML・CSS・JavaScript だけの静的サイトで、GitHub Pages で公開しています。
- `data.js`：温泉の基本情報（1件 = 1施設）
- `map.js`：制覇状況画面の九州地図
- `images/`：各施設の丸窓に出すイラスト（AI生成のイメージ画）

## データの保存先

星評価・感想・訪問日・写真は、**使っている端末のブラウザの中だけ**に保存されます。サーバーには送られず、他の人からは見えません。ブラウザのデータを消したり機種変更をしたりすると、記録も消えます。

## 注意

- 営業時間・料金・定休日などは観光情報サイト等で調べたもので、変わることがあります。お出かけ前に各施設へご確認ください。
- 地図の出典：地球地図日本（国土地理院）。[dataofjapan/land](https://github.com/dataofjapan/land) の `japan.geojson` を簡略化して使用しています。
